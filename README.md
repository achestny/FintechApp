# ניהול לקוחות בנק – אפליקציית דמו

אפליקציה סטטית (HTML/CSS/JavaScript, ללא שרת) לניהול לקוחות בבנק, בעברית ומיושרת לימין.
מיועדת לאירוח ב-GitHub Pages.

## ישויות
| ישות | מפתח ראשי | קשרים |
|---|---|---|
| לקוחות | תעודת זהות | משויך לסניף (N:1), מחזיק בחשבונות (N:M), לוקח הלוואות (1:N) |
| חשבונות | מספר חשבון | מתנהל בסניף (N:1), כולל תנועות (1:N) |
| בעלות בחשבונות | ת.ז + מספר חשבון (משולב) | טבלת הקשר N:M בין לקוחות לחשבונות |
| תנועות | מזהה תנועה | שייכת לחשבון |
| הלוואות | מספר הלוואה | שייכת ללקוח |
| סניפים | קוד סניף | – |
| עובדים | מספר עובד | מועסק בסניף (N:1), "מנהל של" – קשר רקורסיבי (1:N) |

## קבצים
- `index.html` – האפליקציה (לוח בקרה, רשימות, הוספה/עריכה/מחיקה, תצוגת רשומה עם רשומות קשורות)
- `erd.html` – עמוד תרשים ישויות-קשרים (ERD) בסימון Chen + טבלת קשרים + מעבר לטבלאות
- `assets/schema.js` – מודל הנתונים ונתוני הדגמה
- `assets/app.js`, `assets/erd.js`, `assets/style.css`

הנתונים נשמרים ב-localStorage של הדפדפן. כפתור "איפוס לנתוני הדגמה" מחזיר את המצב ההתחלתי.

## העלאה ל-GitHub Pages
1. צרו מאגר (repository) חדש ב-GitHub.
2. העלו את כל תוכן התיקייה (כולל `assets/` ו-`.nojekyll`) לשורש המאגר.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, Folder: `/ (root)` → Save.
4. אחרי כדקה האתר יהיה זמין בכתובת `https://<שם-משתמש>.github.io/<שם-המאגר>/`.
